 🎲 Python Dice Rolling Game

A simple, interactive command-line dice rolling simulator built using Python. This is my very first Python project, designed to practice loops, conditional logic, and utilizing built-in modules.

---

🚀 Features

* **Dual Dice Roll:** Simulates rolling two six-sided dice simultaneously.
* **Input Validation:** Automatically handles uppercase and lowercase inputs (e.g., `Y` or `y`) and catches invalid responses.
* **Infinite Replayability:** Uses a game loop that allows you to roll as many times as you want until you choose to exit.

---

🛠️ Prerequisites

To run this game, you only need **Python 3.x** installed on your computer. It uses Python's built-in `random` module, so no external libraries or installations are required.
